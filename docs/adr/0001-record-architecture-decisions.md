# 1. Record architecture decisions

Date: 2026-11-10 · Status: Accepted

## Context
The project plan is a private working document. Decisions about architecture, data sources and
trade-offs must still be traceable for anyone reading the code, including future me.

## Decision
Each significant decision gets a short ADR in `docs/adr/`, numbered, never rewritten after acceptance.

## Consequences
Reviewers see *why* the system looks the way it does, including what was deliberately removed.
Writing one costs a few minutes per decision.
